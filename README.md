# Leave Application System

A simple Leave Application System built using **HTML**, **CSS**, and **JavaScript**. This project allows users to submit leave requests and view their submitted applications in a clean and user-friendly interface.

---

## 📌 Features

* User-friendly leave application form
* Validations for required fields
* Stores leave data in local storage (browser)
* Displays list of submitted leave applications
* Responsive and clean UI design

---

## 🛠️ Technologies Used

# **HTML5** – Structure of the application
# **CSS3** – Styling and responsive layout
# **JavaScript** – Logic, validation, and data handling

## 🚀 Getting Started



## 📄 Usage Instructions

1. Open the leave application form
2. Enter your details:

   * Name
   * Department
   * Leave Type
   * From & To dates
   * Reason for leave
3. Click **Submit**
4. Your leave application will appear in the "Submitted Leaves" section
5. Data persists using the browser's local storage
